Perguntas frequentes

O que você precisa saber

Transparência faz parte de uma boa decisão financeira.

A simulação garante que meu empréstimo será aprovado?

Não. A simulação é ilustrativa e não representa uma oferta, aprovação ou garantia de crédito.

O valor da parcela é definitivo?

Não. O valor mostrado usa uma taxa mensal ilustrativa de 3% apenas para demonstrar o cálculo. Uma proposta real deve informar taxa, CET, tributos, tarifas e demais condições aplicáveis.

Meus dados são enviados quando preencho o formulário?

O site não envia os dados automaticamente. Se você clicar em “Continuar pelo WhatsApp”, abrirá uma mensagem preenchida para o número de atendimento; você poderá revisar e só enviará ao tocar no botão de enviar do WhatsApp.

O Crédito Ágil é uma instituição financeira?

Esta página é um protótipo de interface. Antes de oferecer crédito real, será necessário identificar claramente a empresa responsável, verificar as exigências legais aplicáveis e integrar uma instituição ou serviço autorizado quando necessário.
